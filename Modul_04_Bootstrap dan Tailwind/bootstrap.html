Informasi Praktikum

Praktikum Pemrograman Web merupakan kegiatan pembelajaran yang membantu mahasiswa memahami dasar-dasar pengembangan website. Pada praktikum ini mahasiswa mempelajari penggunaan HTML, CSS, Bootstrap, dan Tailwind CSS untuk membuat halaman web yang terstruktur dan responsif.

Melalui praktikum ini, mahasiswa diharapkan mampu membuat halaman web yang memiliki tampilan rapi, responsif, dan mudah digunakan pada berbagai ukuran layar.
